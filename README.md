# 🚢 Titanic Survival Prediction

A Machine Learning project that predicts whether a passenger survived the Titanic disaster based on passenger information. The project includes data preprocessing, model training, and two interactive application interfaces for making predictions.

---
## 📌 Project Overview

The Titanic Survival Prediction project uses a supervised Machine Learning classification model to predict passenger survival. The model is trained on the Titanic dataset after performing data cleaning and preprocessing. Users can make predictions through two different application interfaces.

---
## ✨ Features

- Predicts Titanic passenger survival using Machine Learning
- Data preprocessing and feature engineering
- Trained classification model
- Two user-friendly prediction interfaces
- Jupyter Notebook for data analysis and model development
- Easy-to-use Python implementation

## 📊 Dataset

The project uses the Titanic dataset containing passenger information such as:

- Passenger Class (Pclass)
- Sex
- Age
- Number of Siblings/Spouses (SibSp)
- Number of Parents/Children (Parch)
- Fare
- Embarked Port

These features are used to predict whether a passenger survived the Titanic disaster.

## 🚀 Installation
1. Clone the repository:

```bash
git clone https://github.com/sanehaverma5/titanic-survival-prediction.git
```

2. Open the project folder in **Visual Studio Code**.

3. Install the required Python libraries:

```bash
pip install pandas numpy scikit-learn streamlit

## ▶️ Running the Project

Open the notebook:

```
Titanic Survival Prediction.ipynb
```
Run the notebook in **Jupyter Notebook**  to explore the dataset, preprocess the data, train the model, and evaluate its performance.

### Step 2: Run the Streamlit Application
Open a terminal in VS Code and run either of the following commands:

```bash
streamlit run app.py
```

or

```bash
streamlit run app2.py
```

The application will open automatically in your web browser.
